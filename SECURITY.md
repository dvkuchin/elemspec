# Security policy

ElemSpec управляет браузером и может взаимодействовать с тестовыми приложениями.
Не публикуйте уязвимости, секреты и данные авторизованных сессий в обычных issues.

Сообщайте об уязвимости приватно через GitHub Security Advisories
(`Security` → `Report a vulnerability`). Не создавайте публичный issue до
согласования исправления.

В сообщении укажите версию ElemSpec, операционную систему, минимальный сценарий
воспроизведения и оценку возможного воздействия. Не проверяйте проблему на рабочих
приложениях и чужих данных.
