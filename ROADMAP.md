# Roadmap ElemSpec

Устройство движка и принятые решения описаны в
[docs/architecture.md](docs/architecture.md). Здесь перечислены публичные
направления развития проекта.

## В работе

- Проверить первый публичный CI-прогон на macOS, Linux и Windows.
- Разделить runtime и authoring-зависимости пакета без ухудшения установки через `pipx`.
- Проверить MCP prompt `new_test` минимум в двух разных ИИ-клиентах.

## Запланировано

- Проверить установку через `pipx` на чистых средах.
- Добавить шаблоны issue/PR и release workflow.
- Реализовать восстановление незавершённых агентских сессий.
- Исследовать Playwright Codegen как источник нейтрального журнала действий.
- При необходимости добавить нативные UX-адаптеры поверх универсального MCP для других клиентов.
- Упаковать интеграцию Codex как публикуемый плагин после стабилизации CLI-установщика.

Рабочие прикладные сценарии, дефекты тестируемых приложений и их долг
`data-testid` должны храниться в независимых проектах спецификаций. В репозитории
движка остаются только явно обозначенные примеры без их локальных evidence и отчётов.
