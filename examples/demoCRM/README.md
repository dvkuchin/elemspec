# DemoCRM

Это два показательных UI-теста вендорского демонстрационного приложения
**DemoCRM**, созданного на платформе **1С:Предприятие.Элемент**.

Репозиторий не содержит адрес конкретного стенда и учётные данные. Перед запуском
скопируйте каталог примера в свой проект тестов и задайте параметры своего
контролируемого тестового окружения.

## Что проверяется

- штатное перенаправление на отдельный сервер авторизации и вход;
- основной каркас приложения;
- основные пункты навигации DemoCRM;
- локаторы `поле "..."` и `пункт навигации "..."`;
- полный обратимый жизненный цикл клиента: создание, проверка строки таблицы,
  открытие, редактирование, подтверждение диалога удаления и проверка удаления.

## Настройка локальной копии

1. В `elemspec.toml` замените `app.example.test` и `auth.example.test` на hostname
   тестового приложения и сервера авторизации.
2. В `init.json` каждого теста замените шаблонные значения параметров:
   `адрес_приложения`, `путь_приложения`, `логин` и `пароль`.
3. Не коммитьте заполненные локальные файлы в публичный репозиторий. Для реального
   проекта тестов храните секреты принятым в вашей команде способом.

Комментарии в feature показывают место настройки, а сами шаги используют только
`${параметры}`. Значения `REPLACE_WITH_...` намеренно не являются рабочими.

## Запуск

Из корня исходного репозитория ElemSpec:

```bash
elemspec --project examples/demoCRM list
elemspec --project examples/demoCRM run democrm-smoke
elemspec --project examples/demoCRM run democrm-client-crud
```

Отчёт будет создан в `examples/demoCRM/_reports/`.

## Ограничения

Это живой интеграционный пример, а не автономный unit-тест ElemSpec. Результат зависит
от доступности внешнего стенда, состояния демо-данных и изменений вендорского приложения.
