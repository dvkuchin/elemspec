# DemoCRM

Это показательный UI-тест вендорского демонстрационного приложения
**DemoCRM**, созданного на платформе **1С:Предприятие.Элемент**.

Пример работает с внешним тестовым стендом:

`https://app-696041216.1cmycloud.com/applications/Demo-CRM-tests`

## Что проверяется

- штатное перенаправление на `auth.1cmycloud.com` и авторизация;
- основной каркас приложения;
- основные пункты навигации DemoCRM;
- локаторы `поле "..."` и `пункт навигации "..."`.

## Запуск

Из корня исходного репозитория ElemSpec:

```bash
elemspec --project examples/demoCRM list
elemspec --project examples/demoCRM run democrm-smoke
```

Отчёт будет создан в `examples/demoCRM/_reports/`.

## Тестовая учётная запись

Логин: `TestUser`  
Пароль: `TestUser`

Учётная запись создана только для тестового окружения. До реализации
механизма secrets эти данные намеренно хранятся в feature-файле. Не используйте
этот подход для рабочих или чувствительных сред.

## Ограничения

Это живой интеграционный пример, а не автономный unit-тест ElemSpec. Результат зависит
от доступности внешнего стенда, состояния демо-данных и изменений вендорского приложения.
